# LinkedIn Reply

Craft authentic, professional, and high-engagement replies for LinkedIn posts based on user-provided post content.

## When to Use

- The user states "I am writing a linkedin reply" or asks to write a reply/comment for LinkedIn.
- The user uses the trigger phrase "linkedin slop".
- The user pastes or quotes a LinkedIn post and asks for a reply or response.

## Steps

1. Review the source LinkedIn post provided by the user to identify key themes, stance, and tone.
2. If the user hasn't provided the post content yet, prompt them to paste the post text.
3. Draft 2 to 3 distinct reply options catering to different conversational angles:
   - Insightful / Value-Add: Adds a constructive insight, personal takeaway, or related perspective.
   - Conversational / Engaging: Asks a relevant follow-up question or expands on a specific point from the post.
   - Snappy / Punchy: A concise 1-2 sentence reaction that cuts straight to the core idea.
4. Ensure comments sound human, avoid empty corporate cliches ("Agree! Great share!"), and maintain natural formatting suitable for LinkedIn comments.

## Gotchas

- Keep replies concise. Long essays in LinkedIn comment sections get skimmed over.
- Do not use em dashes or overly stiff academic prose.
- Make sure each option directly references a specific insight from the original post rather than speaking in vague generalities.
